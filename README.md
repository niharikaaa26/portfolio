# Netflix-Style Portfolio for Niharika M S

## How to use
1. Replace the existing portfolio files with these files.
2. Add your latest resume as `resume.pdf` in the same folder as `index.html`.
3. Update the LinkedIn URL in `index.html`.
4. Push to GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — Netflix-inspired responsive styling
- `script.js` — sticky nav, mobile menu, reveal animations
